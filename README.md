# CallePuzzle Frontend Library

Libraría para crear apps frontend de CallePuzzle.

Este monorepo contiene:
- dos paquetes UI:
  - react-ui
  - sveltekit-ui

- dos demos:
  - usando el framework de astro para probar la librería de react
  - usando sveltekit

Arrancar las demos:

```bash
bun run dev
```

Arrancar el storybook:

```bash
bun run stoybook
```
